VISTA POC DASHBOARD GENERATOR STARTUP GUIDE FOR A NEW TEAM MEMBER
===================================

PURPOSE

This guide explains how to start the Figma-to-Vista Dashboard Generator
locally. You must keep THREE terminal windows running at the same time.

Before starting: - Make sure the project is available at: C:_proj - Make
sure Node.js/npm and Python are installed. - Open the project folder in
your code editor or File Explorer if needed. - Do not close any of the
three terminals while using the application.

PART 1 — START THE FIGMA PLUGIN RECEIVER

1.  Open Windows PowerShell.

2.  Run:

    cd C:_proj python plugin_receiver.py

3.  Wait until you see:

    Waiting for Figma plugin at http://127.0.0.1:8765

4.  Leave this terminal open and running.

5.  Do not press Ctrl+C in this terminal.

This process receives data sent by the Figma plugin.

PART 2 — START THE BACKEND SERVER

1.  Open a SECOND Windows PowerShell terminal. Do not reuse or close the
    first terminal.

2.  Run:

    cd C:_proj python server.py

3.  Wait until you see messages similar to:

    Starting Vista POC Dashboard Generator server on
    http://127.0.0.1:8000 Application startup complete. Uvicorn running
    on http://0.0.0.0:8000

4.  Leave this terminal open and running.

5.  Do not press Ctrl+C in this terminal.

This process runs the backend/API that handles the dashboard-generation
workflow.

PART 3 — START THE FRONTEND

1.  Open a THIRD Windows PowerShell terminal.

2.  Run:

    cd C:_proj npm run dev

3.  Wait until Vite displays a local address similar to:

    VITE ready Local: http://localhost:5174/

    NOTE: The port may differ if 5174 is already in use. Always use the
    exact Local URL printed in your terminal.

4.  Open the Local URL in your browser. Example: http://localhost:5174/

5.  Leave this terminal open and running.

6.  Do not press Ctrl+C in this terminal.

This process serves the user interface in the browser.

PART 4 — CHECK THAT ALL THREE PROCESSES ARE RUNNING

Before using the application, confirm:

Terminal 1 — Plugin Receiver Expected: Waiting for Figma plugin at
http://127.0.0.1:8765

Terminal 2 — Backend Expected: Application startup complete and Uvicorn
running on port 8000.

Terminal 3 — Frontend Expected: Vite ready and a Local URL, for example
http://localhost:5174/

All three terminals must remain open simultaneously.

PART 5 — USE THE APPLICATION

1.  Keep all three terminals running.
2.  Open the frontend Local URL in your browser.
3.  Open the relevant Figma file and launch the Figma plugin.
4.  Follow the plugin’s on-screen instructions to send the selected
    Figma design to the local receiver.
5.  Wait for the processing workflow to finish.
6.  Check the browser for the generated Vista dashboard.
7.  If the dashboard does not appear, check the terminal windows for
    errors.

IMPORTANT

-   Start each process in its own terminal window.
-   Do not run all three commands in the same terminal.
-   Do not close a terminal while using the application.
-   Do not press Ctrl+C unless you intend to stop that process.
-   If a process stops or a terminal is closed, restart that process
    using the corresponding steps above.
-   Use the exact frontend Local URL printed by Vite. Do not assume the
    port will always be 5174.
-   If a port is already occupied, do not randomly change project
    settings. Read the terminal error/output first.

SHUTDOWN PROCEDURE

When finished: 1. Go to Terminal 3 and press Ctrl+C to stop the
frontend. 2. Go to Terminal 2 and press Ctrl+C to stop the backend. 3.
Go to Terminal 1 and press Ctrl+C to stop the plugin receiver. 4. Close
the terminal windows if you no longer need them.

If you are unsure whether a process is still running, check its terminal
before starting another copy. Avoid launching duplicate servers.
